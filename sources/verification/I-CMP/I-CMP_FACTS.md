# I-CMP_FACTS: what the I-CMP lesson and its kit files can rely on

Run date: **2026-10-18**. This file lists every number the I-CMP study-kit files (HTML lesson, gap audit, verify notebook, apply-it tool, questions, reading file) may print, with the run that produced it. Numbers not produced by a run are marked CITED, DERIVED (arithmetic from measured counts), FORMULA, ASSUMPTION, TOY or UNVERIFIED.

**Read this first.** No I1–I6 per-technique run exists yet (no `experiments/E01x` folder, no cached Cohere or LLM call). So this file measures what can be built offline on Corpus D with no API call: units, the heading tree, six **buildable arms** (v0, three I1 grid points, pages, uncapped sections) plus an **I3-style probe**, a deterministic I5 header, and their retrieval on the 8 answerable **draft seeds**. The seeds are `llm-draft` (06 §6.7) and saturate v0 (CE@4 8/8), so every rank, CE value and Δ below is an **observation, never an evaluation result**. I4 and I6 are **not run**: their rows are DERIVED costs only.
